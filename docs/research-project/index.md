# Level 7 — Research Project

Level ini mengajarkan cara **meneliti dengan clustering**: dari merumuskan masalah, menelaah pustaka, memilih dan mendokumentasikan data, menyusun protokol eksperimen, menjalankan dan melaporkan hasil, sampai membuat penelitian yang bisa diulang orang lain. Semuanya dibangun di atas [Level 2](../data-exploration-and-preprocessing/index.md) sampai [Level 6](../experimentation-and-interpretation/index.md), dan ditutup dengan satu proyek akhir yang utuh.

Bab-bab memakai dataset **Breast Cancer Wisconsin (Diagnostic)** dari UCI Machine Learning Repository (lisensi CC BY 4.0 menurut halaman dataset), dimuat lewat scikit-learn. Setiap potongan kode diikuti penjelasannya, dan output yang ditampilkan berasal dari eksekusi nyata.

!!! warning "Bukan penelitian klinis"
    Dataset ini bersifat medis, tetapi tujuan Level 7 hanya **belajar metodologi penelitian clustering**. Tidak ada klaim klinis, dan hasilnya tidak boleh dipakai untuk menilai pasien. Label diagnosis hanya dipakai sebagai validasi eksternal.

!!! note "Contoh ilustrasi dan temuan"
    Angka dari skrip adalah **hasil demonstrasi** pada satu dataset dan satu pengaturan. Bab-bab menandai dengan jelas mana contoh didaktik dan mana yang merupakan temuan proyek akhir (Bab 10), beserta batas kesimpulannya.
