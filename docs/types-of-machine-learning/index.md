# Bab 2 — Types of Machine Learning

*Memahami Supervised Learning, Unsupervised Learning, Semi-Supervised Learning, dan Reinforcement Learning.*

Di [Bab 1](../introduction-to-machine-learning/index.md) kamu sudah tahu bahwa Machine Learning adalah cara membuat komputer belajar dari data. Bab ini menjawab pertanyaan berikutnya: **apakah semua mesin belajar dengan cara yang sama?** Ternyata tidak. Cara belajarnya tergantung pada data yang tersedia dan tujuan yang ingin dicapai.

## Tujuan pembelajaran

Setelah menyelesaikan bab ini, kamu mampu:

- [x] Menjelaskan jenis-jenis Machine Learning.
- [x] Memahami perbedaan mendasar Supervised Learning dan Unsupervised Learning.
- [x] Menjelaskan labeled data dan unlabeled data.
- [x] Memahami Classification dan Regression.
- [x] Memahami Clustering dan Dimensionality Reduction.
- [x] Memahami Semi-Supervised Learning.
- [x] Memahami Reinforcement Learning.
- [x] Memilih pendekatan Machine Learning yang cocok untuk suatu masalah.
- [x] Memahami peran tiap pendekatan dalam penerapan dunia nyata.
- [x] Membuat contoh dasar dengan Python dan Scikit-learn.
- [x] Menjelaskan hubungan jenis-jenis Machine Learning dengan fokus kurikulum ini: Clustering.
