# Level 3 — Fundamental Clustering

Level ini memberi fondasi sebelum kamu mempelajari algoritma clustering di Level 4. Kita belajar apa itu *clustering*, seperti apa kelompok yang baik, bagaimana kelompok diwakili oleh satu titik pusat, bagaimana "mirip" dan "berbeda" diukur dengan jarak, dan bagaimana semuanya tersusun dalam satu alur kerja.

Bab 1, 2, dan 7 memakai dataset **Mall Customers** seperti Level 2. Bab 3 sampai 6 memakai data sintetis kecil dengan `random_state=42`, supaya perhitungan manual mudah diikuti.
