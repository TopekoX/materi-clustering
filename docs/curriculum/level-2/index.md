# Level 2 — Data Exploration and Preprocessing

Algoritma clustering tidak punya "kunci jawaban". Tidak ada label yang memberi tahu apakah hasilnya benar. Satu-satunya pegangan kita adalah **kualitas data**. Karena itu, sebelum memakai algoritma apa pun, kita perlu mengenal data dan menyiapkannya.

Level ini mengajarkan cara mengeksplorasi dan membersihkan data sampai siap di-*cluster*. Seluruh bab memakai satu dataset yang sama: **Mall Customers** (200 pelanggan pusat perbelanjaan).
