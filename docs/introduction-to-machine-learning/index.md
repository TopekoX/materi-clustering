# Bab 1 — Introduction to Machine Learning

Selamat datang! Bab ini adalah pintu masuk ke seluruh materi. Kita mulai dari pertanyaan paling dasar: **apa sebenarnya Machine Learning itu, dan bagaimana mesin bisa "belajar"?**

Tidak perlu khawatir kalau istilahnya terdengar asing. Setiap istilah baru dijelaskan dengan bahasa sehari-hari dan contoh sederhana.

## Tujuan pembelajaran

Setelah menyelesaikan bab ini, kamu mampu:

- [x] Menjelaskan definisi Machine Learning.
- [x] Menjelaskan hubungan Artificial Intelligence, Machine Learning, dan Deep Learning.
- [x] Menjelaskan perbedaan Machine Learning dan pemrograman tradisional.
- [x] Memahami prinsip dasar bagaimana mesin belajar dari data.
- [x] Menyebutkan contoh penerapan Machine Learning di dunia nyata.
- [x] Mengenali komponen dasar sistem Machine Learning.
- [x] Menjelaskan alur kerja (workflow) Machine Learning secara umum.
- [x] Memahami peran Machine Learning dalam masalah clustering.
