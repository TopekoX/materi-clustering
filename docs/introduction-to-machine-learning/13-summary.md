# Ringkasan Bab

## Poin penting

- **Machine Learning** membuat komputer menemukan pola dari data, lalu memakai pola itu untuk menebak hal baru.
- Definisi Mitchell: program belajar jika kinerjanya \(P\) pada tugas \(T\) membaik karena pengalaman \(E\).
- **Deep Learning ⊂ Machine Learning ⊂ Artificial Intelligence.**
- Pemrograman tradisional: *data + aturan → jawaban*. Machine Learning: *data + jawaban → aturan (model)*.
- Alur dasar: kumpulkan data, siapkan data, pilih algoritma, **training**, hasilkan **model**, **prediction**, **evaluation**.
- Istilah dasar: dataset, feature, target, algorithm, model, training data, testing data, prediction, evaluation.
- Data dibagi menjadi data latih dan uji agar model diuji pada data yang belum pernah dilihatnya.
- Workflow ML terdiri dari sembilan langkah, dari mendefinisikan masalah sampai deployment atau reporting, dan sering diulang.
- Jenis masalah: classification, regression, clustering, dimensionality reduction, anomaly detection.
- **Clustering** adalah unsupervised learning: mengelompokkan data mirip **tanpa label**. Manusia yang menafsirkan arti tiap kelompok.
- Hampir semua model Scikit-learn mengikuti pola `model = Algoritma()`, `model.fit(...)`, `model.predict(...)`.
